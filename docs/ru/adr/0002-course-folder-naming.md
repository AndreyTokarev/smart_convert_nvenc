# ADR-0002: Идентичность курса — короткие имена папок + опциональный `course.json`

English: [../../en/adr/0002-course-folder-naming.md](../../en/adr/0002-course-folder-naming.md).

- **Статус:** Принято
- **Дата:** 2026-07-24
- **Контекст:** личный архив видеокурсов; длина путей Windows уже на пределе на глубоких деревьях уроков; метаданные не должны ухудшать пути

## Контекст

Имена папок вроде `[0000] Title [Publisher] [Author]` (или с тегами `[pub:…]` / `[by:…]`) упираются в **MAX_PATH** на вложенных папках уроков. Метаданные всё равно нужны для будущих пакетных инструментов (фильтр, дубликаты, отчёты).

Нужно:

1. **Короткие** человекочитаемые имена папок, когда возможно.
2. **Богатые** метаданные на уровне курса без запихивания их в путь.
3. **Маркер** «этот каталог — корень курса» для будущих пакетных сканов (не только «прямой потомок inbox»).

## Решение

### Разделение: путь vs метаданные

| Задача | Где живёт |
|--------|-----------|
| Идентичность в файловой системе / цель перемещения | Имя папки (непрозрачное; инструмент не переименовывает) |
| Год, название, издатели, авторы, заметки | Опциональный **`course.json`** в **корне курса** |
| «Это корень курса?» | Наличие `course.json` (основной маркер); под `inbox/` любая папка первого уровня всё равно курс даже без JSON (ADR-0001) |

### Имя папки (целевое, опциональная полировка)

Держать имена **короткими**. Плейсхолдер года достаточен для простой сортировки; **не** кодировать издателя/автора в пути.

```text
[0000] 20 Sick Licks
[2024] Complete Jazz Guitar
20 Sick Licks
```

Нетегированные `[Publisher]` / `[Author]` в имени папки **допустимы, но нежелательны** (длина пути).  
**Отвергнуто для целевого варианта:** тегированные скобки `[pub:…]` `[by:…]` — лишние символы без выигрыша, когда есть JSON.

### `course.json` (предпочитаемые метаданные)

**Путь:** `<course_root>/course.json`  
**Роль:** маркер корня курса + метаданные для всего дерева (все вложенные файлы/каталоги наследуют этот контекст курса).

Минимальная схема (поле версии `schema` для обратной совместимости):

```json
{
  "schema": 1,
  "title": "20 Sick Licks",
  "year": null,
  "publishers": ["Jam Track Central"],
  "authors": ["Matteo Mancuso"],
  "notes": ""
}
```

| Поле | Тип | Примечания |
|------|-----|------------|
| `schema` | int | Сейчас `1` |
| `title` | string | Каноническое название (может отличаться от имени папки) |
| `year` | int \| null | `null` или опустить = неизвестно (то же, что `[0000]` в папке) |
| `publishers` | string[] | Пусто / опустить, если неизвестно; несколько организаций → несколько записей |
| `authors` | string[] | Пусто / опустить, если неизвестно |
| `notes` | string | Опциональный произвольный текст |

Правила:

- Файл **опционален**. Нет JSON → курс всё равно валиден; метаданные неизвестны.
- Инструмент **обязан сохранять** `course.json` как любой другой невидеофайл (перенос с курсом в outbox).
- Инструмент **не требует** JSON для кодирования (MVP-компрессор без изменений).
- Будущие пакетные задачи: если в каталоге есть `course.json`, считать его корнем курса даже вне стандартной раскладки inbox.
- **Не** изобретать per-file sidecar JSON в MVP; уровня курса достаточно.

### Runtime (MVP encode pipeline)

Без изменений относительно [ADR-0001](./0001-course-inbox-outbox-tmp.md):

- Единица работы = папка первого уровня под `inbox/` (с `course.json` или без).
- Прокидывать имя папки как есть; не переименовывать автоматически.
- Курсы без видео: pass-through в outbox (JSON уезжает вместе с ними).

### Будущее (не MVP)

- Читать `course.json` в GUI / отчётах / поиске дубликатов (F6).
- Опциональный хелпер «записать заглушку `course.json`» при импорте голой папки.
- Опциональная валидация / bump `schema`, когда поля расширятся (например tags, source URL).

## Последствия

- Пути остаются короче; богатство метаданных переезжает в один небольшой файл в корне.
- Пакетные инструменты получают надёжный маркер корня без разбора «фольклора» имён папок.
- Папка `[0000]` и JSON `"year": null` могут сосуществовать; когда оба есть, **JSON побеждает** для отображения метаданных; имя папки остаётся идентичностью в ФС.
- Поиск дубликатов должен предпочитать title/publishers/authors из JSON хрупкому разбору имени.

## Отвергнуто

| Альтернатива | Почему нет |
|--------------|------------|
| Тегированные скобки в именах папок (`pub:` / `by:`) | Удлиняют пути; JSON понятнее |
| Требовать `course.json` перед кодированием | Блокирует сжатие существующего архива |
| Автопереименование папок из JSON | Смена идентичности; риск для outbox/дубликатов |
| Скрытый `.course.json` | Легко не заметить в Explorer; видимость > хитрость |
| Per-file metadata JSON рядом с каждым видео | Шум; наследование на уровне курса пока достаточно |
