# tmp (work area / рабочая зона)

Temporary encode files and draft assembly. / Временные файлы encode и черновая сборка.

- Do not store source courses here manually. / Не храните исходные курсы здесь вручную.
- Safe to delete when no encode is running. / Можно удалять, когда encode не идёт.
- ADR-0001: [EN](../../docs/en/adr/0001-course-inbox-outbox-tmp.md) · [RU](../../docs/ru/adr/0001-course-inbox-outbox-tmp.md).
