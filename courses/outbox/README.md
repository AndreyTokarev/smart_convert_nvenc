# outbox

**EN:** Processed courses land here:

- if total size decreased — compressed videos + all non-video files;
- if not — the original course unchanged.

Do not put new courses here for compression — this is output only.

- если нет — исходный курс без изменений.

Новые курсы для сжатия сюда не кладите — это только вывод.
